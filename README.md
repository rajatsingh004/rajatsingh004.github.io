# Rajat Singh — engineering portfolio

A responsive, single-page portfolio for DevOps, Platform Engineering, and SRE roles. It leads with an end-to-end ECS-to-EKS migration, followed by a sanitized CyberArk onboarding engagement and public engineering artifacts. Built with plain HTML, CSS, and JavaScript, with no build step or external runtime dependencies.

## Preview

Open `index.html` in a browser, or serve this folder with any static web server. Google Fonts load from Google Fonts when online; system fallbacks are included.

## Contents

- `index.html` — selected professional and repository projects, an experience timeline, engineering skills, certifications, and contact details
- `styles.css` — responsive layout and visual system
- `script.js` — interactive release and incident scenarios, plus light reveal animation

The project cards link to Getto, Kube-Work, Work-Work-Work, and Konkey artifacts. Professional client work is summarized without publishing client infrastructure or private onboarding material. The résumé link points to the Google Drive URL supplied for the portfolio.

## Publish with GitHub Pages

Create a public repository named `rajatsingh004.github.io` and push the files in this folder to its `main` branch. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. GitHub Pages will publish the site at `https://rajatsingh004.github.io/`.

GitHub Pages hosting for a public repository is free. A custom domain is optional and must be registered separately.
